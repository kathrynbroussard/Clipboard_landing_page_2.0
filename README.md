# Clipboard landing page 2.0 - Frontend Mentor

A fully responsive landing page challenge from Front-End Mentor

## About this project

This project was built entirely from scratch without using any tutorials, walkthroughs, or external video guides. I built this independently to test my front-end layout skills and responsive design practices.

WHAT I DID DO:
I did look at the desktop and mobile previews provided by Front-End Mentor and did my best to re-create the same look. I also utilized Chat GPT and other resources online to help me when I was stuck.
As well as the style-guide.md via FEM in order to use the same fonts and colors as the preview.

Link to site for reference:

[Frontend Mentor](https://www.frontendmentor.io) challenges help you improve your coding skills by building realistic projects.

## My main goal

I originally attempted to do the first version perhaps before I was ready and before I learned grid. I was still struggling to understand Flexbox completely and to be honest it took me 3 days to complete it because at almost every step I had issues. 

After watching many videos of a Youtuber, Future Fullstack, I took notes and practiced on VCS what I learned. By the way, his channel has nothing to do this Front-End Mentor. I decided I wanted to try the Clipboard landing page again to see if I could complete the project with more ease. 

## My outcome

Overall I am proud of my progress becauase I was able to finish the project in one day and I only had 2-3 minor moments were I had to resort to asking Chat GPT something.

## What I would add if I did a 3rd version

- Add comments in my HTML by labeling the different sections.
- Add custom properties for the font sizes, colors etc.
